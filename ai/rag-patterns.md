# RAG Patterns

Retrieval-Augmented Generation combines a retriever with a generator.

## Common Patterns
1. **Naive RAG** — embed, retrieve top-k, concatenate into prompt
2. **Agentic RAG** — agent decides when to retrieve
3. **Graph RAG** — knowledge graph enriched retrieval

## Chunking Strategies
- Fixed-size with overlap
- Semantic splitting
- Document-aware
